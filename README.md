### What I learned

In this project I learned that within picture element we can use source element with media attribute set to max-width: 48rem means if width crosses 48rem then use deskop image if screen size is below 48rem then I added img element inside picture element which was a fallback so it will use mobile image for smaller screens.

### Continued development

This was my first project with media query and picture element so I would like to practice more on picture element and media query to get comfortable with that.
